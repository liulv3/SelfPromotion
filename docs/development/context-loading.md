# 新会话与渐进式上下文

根 `AGENTS.md` 是唯一核心正文，`AGENT.md` 只是兼容指向。标准发现行为和资料来源见 [方法调研](methods-research.md)。

## 读取路径

1. 自动载入或显式读取核心约定；接着读 [索引](../INDEX.md)与[状态](../STATUS.md)。
2. 从用户目的选最窄路径。例如“修复 Zotero 同步”先读当前架构与文献模块，不先读 PPT 或全部研究报告。
3. 只在需要证据、接口或历史取舍时展开下一层；记录本轮实际采用的决策，不把未读文档当作已知。
4. 改动代码前检查目标路径上的局部 AGENTS；根会话不保证已经载入子目录规则。
5. 结束时写明完成内容、真实验证和下一步；复杂持续任务可在 `docs/development/work-items/` 保存短任务记录，没必要为每次小改动创建文件。

## 防止信息漂移

优先级为用户当前明确指令 → 适用核心/局部约定 → 当前已采纳 ADR 与当前文档 → 历史讨论/调研。证据冲突须明确指出，不因旧方案篇幅较长就优先它。索引不是自动上下文加载器；上述按需读取是执行约定。

当前架构改变时同步更新当前文档、状态与相关索引；旧决策标为被替代，保留原因。个人论文笔记和运行日志放被忽略的数据目录，避免被误当项目开发规范。只有重复稳定的开发操作才值得提炼为 Skill；产品自己的阅读/PPT Skill 与开发助手的指令不是同一类文件。
